# Customer Churn Prediction using Logistic Regression

## 📌 Project Overview

This project uses **Logistic Regression** to predict whether a customer is likely to churn in the next billing cycle.

The project was completed as part of my **Machine Learning internship at LearnDepth Academy LLP**.

The main objective was to understand the complete machine learning workflow, from data preprocessing to model evaluation.

## 🎯 Objective

To build a binary classification model that predicts customer churn based on customer-related features.

* `0` → No Churn
* `1` → Churn

## 📊 Dataset

The dataset contains customer information such as:

* Tenure in months
* Monthly charges
* Support tickets
* Average session minutes
* Late payments
* Contract duration

The target variable is `target`.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## 🔄 Machine Learning Workflow

1. Load the dataset
2. Inspect the dataset
3. Check data types
4. Check missing values
5. Check duplicate records
6. Analyze target class distribution
7. Separate features and target
8. Split data into training and testing sets
9. Standardize numerical features
10. Train Logistic Regression model
11. Generate predictions
12. Evaluate model performance
13. Analyze the confusion matrix
14. Interpret model coefficients

## 🤖 Model Used

### Logistic Regression

Logistic Regression is a supervised machine learning algorithm commonly used for binary classification problems.

In this project, it is used to predict whether a customer belongs to the churn or non-churn class.

## 📈 Evaluation Metrics

The model is evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* ROC-AUC
* Confusion Matrix

### Confusion Matrix

The confusion matrix helps identify:

* True Positives (TP)
* True Negatives (TN)
* False Positives (FP)
* False Negatives (FN)
